To add or correct a credit, propose an edit with your preferred name or GitHub
handle. In the pull request, mention the contribution so maintainers can verify it.
For a credited GitHub profile, take its avatar from `https://github.com/HANDLE.png?size=96`,
crop it to a 96 × 96 circle with transparent corners, and save it as
`docs/contributors/HANDLE.png`. Link the image to the profile in the README.
Third-party code and its authors are listed in [Code provenance](docs/CODE_PROVENANCE.md).
